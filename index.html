无尽群岛

Endless Archipelago · Sailing & Naval Combat Sandbox

驾驶你的帆船，利用 风向 在程序化群岛中航行、测绘岛屿、规避浅滩与暴风雨， 并与海盗船展开两舷炮战。

  • W / S 升帆 / 降帆　A / D 左舵 / 右舵
  • Q / E 微调帆向（让帆面尽量垂直迎风）
  • 空格 抛锚 / 起锚　V 切换第一人称　Z 按住 望远镜
  • 鼠标左键 左舷齐射　鼠标右键 右舷齐射
  • 鼠标移动 环绕视角　滚轮 缩放　F3 调试面板
  • ESC 暂停菜单（可保存世界、调整视距 / 灵敏度 / 画质）

目标：击沉所有海盗船（小地图红点）。顺风满帆、顶风停船——读懂风，才能读懂大海。

暂停

画质影响波浪幅度、植被密度与阴影，切换即时生效。

建议使用桌面浏览器

本游戏需要键盘与鼠标操作，请在桌面端 Chrome / Edge / Firefox 中访问。
