# 无尽群岛 —— 程序化群岛帆船航海与海战模拟器

第三人称 3D 航海沙盒：驾驶帆船在程序化群岛中利用风向航行、测绘岛屿、规避浅滩、与海盗船炮战。

- 技术栈：HTML5 + CSS3 + 原生 JavaScript ES Modules + Three.js r160（CDN importmap，版本写死）
- 无后端、无外部图片 / 模型 / 音频，所有纹理由 Canvas 2D 动态生成（NearestFilter 像素风）
- 无物理引擎、无噪声库、无第三方 AI 库，地形噪声、船舶动力学与 AI 全部自实现

## 运行方式

项目使用 ES Modules + importmap，**不能直接双击 `index.html`**（file:// 会被 CORS 拦截），需要本地静态服务器：

方式一（Python，推荐）：

```bash
python -m http.server 8000
```

方式二（Node）：

```bash
npx serve .
```

然后在浏览器访问：

```
http://127.0.0.1:8000/
```

建议使用桌面端 Chrome / Edge / Firefox 并开启硬件加速；移动端会提示改用桌面浏览器。

## 玩法要点

- 帆效率由船头与风向夹角、帆桁朝向、帆展开比例共同决定：**顺风接近满速（约 12 节），横风约 6 节，顶风几乎失速（约 1 节）**。HUD 帆效率条与航速实时对应。
- 罗盘顶部的蓝色箭头表示风的来向；让箭头指向船尾方向即为顺风。
- 注意水深，浅水会搁浅、暗礁会撞船掉耐久；耐久归零会沉没并在安全水域重生。
- 敌船需进入视野（望远镜更远）才会被“发现”并显示在小地图上。
- 航行状态、战果、测绘与设置会自动保存到 localStorage，刷新后自动恢复。

## 文件结构

```
index.html        入口页面与所有菜单 / HUD 容器
style.css         全部 UI 样式
src/main.js       游戏入口、渲染/光照、天空、昼夜天气、主循环、输入与存档流程
src/world.js      多层噪声地形、12×12 区块动态加载/卸载、两级 LOD、植被与礁石实例化
src/ocean.js      Gerstner 波浪着色器、深浅水过渡、岸边泡沫、CPU 波高/法线采样
src/ship.js       程序化船模、自实现船舶动力学、帆效率、舵效、锚、浮力姿态、两舷火炮
src/enemy.js      海盗舰队与六态状态机 AI（巡逻/发现/追击/侧舷对准/齐射/撤退）
src/combat.js     炮弹池、重力+阻力弹道、入水水柱/跳弹、球体命中判定、烟雾火光特效
src/camera.js     阻尼跟随相机、鼠标环绕、缩放、防穿模、第一人称与望远镜 FOV
src/ui.js         罗盘、帆效率/航速/水深/耐久/装填 HUD、调试面板、菜单交互
src/minimap.js    按种子预渲染的圆形小地图、玩家与已发现目标、已测绘岛屿
src/textures.js   Canvas 2D 程序化像素纹理（木纹/帆布/旗帜/浪花/烟雾/云等）
src/noise.js      自实现 Perlin / 值噪声 / fB分形 / ridged 山脊噪声与确定性随机
src/save.js       localStorage 存档读写与清除
```
